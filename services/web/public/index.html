WhileYouWait

Deduction puzzles for developers, for while the build runs. A new one of each every day, and you can take as long as you like.

  • Loom

    Weaving

    Set the threads and treadles of a small loom so the cloth weaves the day's pattern. Every tap redraws the cloth.

  • Root Cause

    Incident

    Alerts cascade through a service graph. Check logs and attempt fixes to find which services actually broke, before the downtime adds up.

  • Flaky

    Test suite

    CI is red because of hidden order dependencies between tests. Design runs to find them in as little CI time as you can.

  • Hexroute

    Light routing

    Rotate hex tiles to route red, green and blue light so each receiver gets exactly its colour.
